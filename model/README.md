# Vehicle model

Place the supplied Maruti 800 model here.

Recommended structure:

- `source/` — untouched original model
- `working/` — editable copy
- `exports/` — GLB, STEP, OBJ, renders, or other derived files
- `references/` — photographs and diagrams used for modelling

Record the model's original filename, format, scale, coordinate system, licence/source, and any known missing components before editing it.
